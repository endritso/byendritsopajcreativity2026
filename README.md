# ES VISUALS — Endrit Sopaj

Personal creative portfolio for video editing, photography, social media design, Canva design, branding and content creation.

## View locally
Open `index.html` in a browser.

## GitHub Pages
In the repository, open **Settings → Pages**, choose **Deploy from a branch**, select `main` and `/ (root)`, then click **Save**. The site will be published at:
`https://endritso.github.io/byendritsopajcreativity2026/`

`Endrit_Creative_OS.html` is preserved as the original personal creative planning tool.
